# SlingScan for Mac

Downloads for SlingScan for Mac, the desktop half of [SlingScan](https://slingscan.infinitetoken.com): scan barcodes and QR codes with your iPhone, and SlingScan types them into the app in front on your Mac, like a USB barcode scanner.

**[Download the latest version](https://github.com/infinitetoken/SlingScan-Releases/releases/latest/download/SlingScan.dmg)** (for Macs with Apple silicon), or see [the website](https://slingscan.infinitetoken.com) for help and the iPhone app.

This repository only holds releases: the signed and notarized DMG, and the files SlingScan for Mac checks to update itself. Help and support are at [slingscan.infinitetoken.com](https://slingscan.infinitetoken.com/support).
